# Examples

Example configuration showing every Moments option. Copy what you need into your own Home Assistant and replace the example entity ids with yours. Nothing here is installed by Moments itself.

| File | What it shows |
| --- | --- |
| [dashboard.yaml](dashboard.yaml) | The full dashboard config, every option annotated |
| [time-of-day.yaml](time-of-day.yaml) | A time-of-day helper and the automation that sets it |
| [cards.yaml](cards.yaml) | Each card used on its own in any dashboard |
