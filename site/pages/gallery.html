    Icons

    Icons

    Animated, state-aware icons drawn by moments-tile. The set is picked from the entity's domain and device class, so every common Home Assistant type gets one; appliances are named with icon_set. Icons only move while the device is active, and stop when Reduce Motion is on. Glow is the default; switch to Crisp above, per tile with icon_style, or theme-wide with moments-icon-style.

    Theme and backdrops

    The cards look right in any theme. The Moments theme gives the whole dashboard, stock cards included, the same look, and sets the defaults for icon style and tile surface. Eight backdrops ship with each release; copy them to /config/www/moments/backdrops/. Theme docs.

    Putting it together

    An area view keeps the same sections in the same order in every area: header, lighting, climate and air, windows and doors, devices. The Home view has one section per floor, and each area card opens the view whose path is its area id. Compose a dashboard.
